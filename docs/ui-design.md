# Reading Hub 界面规范

## 方向

阅读优先，导航紧凑，正文舒展。参考 [PaperRss](https://github.com/ohmyangboy/PaperRss) 的纸感底色与衬线正文，以及 [Qiaomu AI RSS 的设计说明](https://github.com/joeseesun/qiaomu-ai-rss/blob/main/DESIGN.md) 中的克制工具栏和清晰阅读层级。参考项目仅用于确定方向，没有复制其代码、字体或素材。

## 字体与控件

| 用途 | 统一规则 |
| --- | --- |
| 界面 | `--font-ui`：macOS 系统字体与中文系统回退。列表标题、弹窗、设置、按钮和 AI 面板保持一致。 |
| 阅读正文 | `--font-reading`：Iowan Old Style、宋体及系统衬线回退，用于文章标题、正文和引用。 |
| 代码 | `--font-mono`：系统等宽字体。公式继续由各数学渲染器管理。 |
| 普通操作按钮 | 最小高度 32px、12px 字号、600 字重、8px 圆角；布局位置由所在组件管理。 |
| 主要操作 | 统一蓝色实底；次要操作使用浅底边框；危险操作使用红色边框与文字。 |
| 图标与导航 | 保留紧凑尺寸和独立选中语义，圆角复用控件变量。键盘焦点和禁用状态必须可辨识。 |

控件基础样式集中在 styles.css，组件通过颜色变量声明语义，不再分别设置按钮外观。正文中的加粗属于正文语义，AI 角色标签只能通过直接子元素选择器设置外观。

AGENTS.md 新增字体、按钮与阅读优先的长期复用规则。静态样式检查要求组件复用字体变量；原生视觉检查跨 AI、来源确认、设置三个面板比较主按钮的字体、尺寸、字重、圆角和颜色，并检查 AI 加粗的行内语义。

1532 项单元/集成测试、构建、样式检查通过。最终原生交互和四档视觉（1024、1280、1440 且 125% 字号、1720）均通过；实际检查默认、窄窗口和打开文章的合成内容截图。图片、表格、代码、公式、滚动区、侧栏、全屏与 AI 面板沿用原有视觉门禁。

全来源阅读审计覆盖 32 个来源的 63 个最新及历史样本：61 个通过，2 个因无法确认远端 robots.txt 规则而安全跳过，不能计为通过。内容模式为 53 个正文、7 个 Feed 正文、1 个 Feed 摘要，以及 2 个受限原文入口。网络层未在此次纯界面改动后重复检查；此前同轮的页面快照一致性修复已通过原生网络检查。

截图和原始审计仅保留在临时目录；不修改用户数据、来源规则、凭据或数据库结构。更新后重启应用可加载全部改动。

## 2026-09-08 模态交互统一

来源弹窗原先仅声明 aria-modal，没有实际把焦点移入弹窗、阻止背景聚焦或处理 Escape；旧构建在新增原生焦点检查中失败。图片预览则单独管理自动聚焦和全局 Escape。两条路径现在复用 ModalSurface，通过原生 dialog.showModal/close 管理顶层模态、背景不可交互和焦点恢复，依据 [HTML dialog 标准](https://html.spec.whatwg.org/multipage/interactive-elements.html#the-dialog-element)。React 仍拥有是否显示的状态，cancel 事件调用当前关闭回调，卸载时关闭原生模态。

保留来源弹窗背景点击不关闭、图片预览背景点击关闭的规则；点击图片内容不关闭。划词工具栏的 Escape 不再越过已打开的模态层清除背景选择状态。删除被共享容器替代的图片自动聚焦、全局 Escape 分支和旧 hidden 样式。原有字体、按钮和正文布局保持不变。

新增三个组件生命周期测试并通过全量 151 个文件、1545 项测试；npm run build、npm run audit:style、git diff --check 通过。jsdom 不实现原生 dialog 方法，测试替身仅模拟开关状态，不作为焦点或背景隔离的证明。真实 Electron 交互覆盖来源与图片的焦点进入、Tab/Shift+Tab、Escape、入口焦点恢复和背景点击差异。四档原生视觉夹具也改用真实 dialog，确认预览正文滚动、固定操作区和大图视口约束；首次夹具在关闭后读取滚动尺寸得到零值，修正读取时序后四档均零失败。人工检查了真实来源弹窗在 125% 字号下的截图。

全来源阅读审计覆盖 32 个来源的 63 个最新/历史样本，63 个通过、零 issues；56 个原文、6 个 Feed 正文、1 个 Feed 摘要，包含科学空间、普通网页/RSS、知乎及学术来源。Feed 回退通过不代表原站全文恢复。AI 学习公式另由原生阅读交互与视觉夹具覆盖。没有增加权限、外部资源、凭据访问或数据库迁移；本次交互规则属于既有界面一致性要求，AGENTS.md 无新增长期规则。更新后重启应用加载共享模态容器。
### 来源设置的固定操作栏

来源设置复用确认弹窗的纵向布局与固定操作栏。内容在独立区域滚动，保存与取消始终可见；错误放在滚动体外，避免失败提示藏在长表单底部。保留统一字体与主次、危险按钮样式。2026-09-08 的原生检查覆盖 1024、1280、1440（125% 字号）与 1720 窗口宽度，验证滚动前后保存按钮位置稳定且位于窗口内；来源设置和校准各保留四档合成数据截图供审查，截图不提交仓库。
## 列表空状态

空状态先区分载入中、载入失败和搜索无结果，再说明当前来源或阅读分类。首次添加来源的引导只出现在没有来源且成功载入的收件箱中；收藏、未读、历史和最近删除使用各自说明。清除搜索恢复输入框焦点，重试保留当前查询，添加来源复用标题栏的同一入口。

布局使用现有本地图标、界面字体及较轻的标题层级，移除装饰编号。长关键词在说明中换行，不撑宽列表；操作按钮通过 action-button 接入共享字体、尺寸、圆角和主次配色，不另定义按钮外观。原生检查覆盖四档窗口、125% 字号、长关键词、按钮边界与焦点恢复；窗口审计等待实际内容尺寸与缩放一致后再读取几何位置。

## 筛选计数与未完成读取

标题计数与分页说明使用当前可见卡片数；仍有下一页时保留加号，并避免宣布整个筛选为空。完整刷新期间“加载更多”不可提交，空页依次区分载入、失败、后续页和最终无结果。

侧栏统计尚未完成首次读取或上次读取失败时显示“—”，配合“计数暂未更新”的可访问说明。关闭提示或开始重试不会使旧数字变为有效结果；读取成功后恢复数字。2026-09-09 原生回归覆盖取消最后一篇收藏、刷新失败、恢复收藏和四档窗口，保持现有字体、按钮及错误布局。

## 通知与撤销操作

通知消息、关闭按钮和撤销操作分开布局。消息保持普通文本和状态播报，可换行并在超过 9em 高度时独立滚动；区域可用键盘聚焦并显示焦点。关闭按钮固定在右上角，撤销操作位于下方，使用共享 action-button；关闭图标复用标题栏/阅读工具栏的控件外观。

长错误不能把操作挤出列表列，也不能因为撤销忙碌而阻止关闭通知。2026-09-09 原生检查覆盖无空格长诊断消息、四档窗口与 125% 字号，并比较撤销按钮的字号、字重、尺寸和圆角。

## 卡片操作

卡片操作复用 action-button 的字号、字重、最小高度和圆角；局部规则只设置紧凑间距、透明背景与语义颜色。操作区允许换行，图标按钮也保留至少 32px 的点击宽度。移除原先独立的 10px 文字和下划线悬停规则。

已读操作明确写成“标为已读／标为未读”。收藏按钮用稳定的可访问名称和 aria-pressed 表示切换状态，提示文字说明收藏或取消收藏；状态变化仍以已确认写入为准。恢复内容使用普通操作配色，删除保留危险配色。2026-09-09 原生检查覆盖四档窗口及 125% 字号，确认共享样式和卡片边界。

## 分页重试

下一页读取失败时，已加载卡片继续显示。错误位于分页说明和原有加载按钮之间，按钮改为“重试加载”，忙碌时显示“正在加载…”并禁止重复点击。重试成功后恢复正常分页状态，切换来源或分类不会携带旧查询的分页错误。

分页反馈独立于顶部操作通知，不能替换删除撤销。错误保持普通文本、可访问的警报和键盘焦点，长内容换行并在有限高度内滚动；重试按钮复用已有共享按钮样式。2026-09-09 原生验证覆盖四档窗口及 125% 字号，检查长诊断消息、重试可达性和撤销保留。

## 阅读偏好的生效与保存

设置页和阅读器共享同一份阅读密度与字号，切换页面保留当前选择。首次打开不自动重写偏好；用户调整后立即生效，再尝试保存到本机。保存失败时，两处使用相同提示“排版已生效，但尚未保存到本机。”和共享样式的“重试保存”按钮；重试保存最新选择，成功后提示消失。未保存的选择只保证在当前应用会话中保留。

阅读器将工具栏和保存提示组成顶部区域，正文仍在独立的剩余空间滚动，保存失败不卸载或重写文章 DOM。设置页的提示放在排版卡片中。密度控件使用 aria-pressed 表示选择，字号按钮在两处统一使用“缩小字号／放大字号”名称。原生故障夹具覆盖四档窗口和 125% 字号、正文身份、跨页面保留和重试恢复。

## 来源状态与长名称

来源状态、设置操作和最近错误分别展示。设置入口复用共享 action-button，未提供配置能力时只显示状态。最近错误默认收起，使用原生 details/summary 展开，长文本可聚焦并在有限高度内独立滚动；同一来源更新保留展开状态，切换来源重置。

列表标题最多显示两行，侧栏分组名单行省略；完整名称保留在文本和悬停提示中，计数不随长名称被挤出列。通知、分页和来源错误共用长文本约束及焦点样式。2026-09-09 原生回归覆盖四档窗口、125% 字号、有效范围内的长名称、详情键盘展开与来源设置入口。

## 侧栏导航与已取消订阅来源

阅读分类和来源条目统一用 aria-current 标记当前导航目标。选择来源时，阅读分类不再同时声明为当前目标；可见选中样式与可访问状态使用相同条件。

已订阅和已取消订阅来源复用同一行组件，均支持右键、ContextMenu 键与 Shift+F10 打开配置。已取消订阅行的独立入口使用设置图标和明确的“打开…的来源设置”标签，点击仅打开设置；重新订阅仍在来源设置中执行。图标按钮复用共享操作控件的尺寸和圆角，四档窗口及 125% 字号下保留可用点击区域。

## AI 配置读取与恢复

首次进入设置时显示服务配置读取状态，未获得服务信息前不显示模型与密钥输入。读取失败或返回空服务列表时提供“重新读取”，按钮复用共享 action-button；读取成功前禁用配置编辑和提交。

保存或清除已经完成、随后读取失败时，提示明确说明“设置操作已完成”，重试只读取配置，不重复写入。恢复后保留原来选择的服务；真正的写入失败仍保留草稿供重试。错误为纯文本警报，复用有限高度的长文本滚动与键盘焦点规则，四档窗口及 125% 字号下保持重试可达。

## AI 回答署名与面板设置

每条 AI 回答显示发起该问题时的服务名称。切换服务、重新读取服务元数据或最小化后恢复面板，都不改变已显示回答的署名；失败及中断回答也保留原服务身份。

服务行的“设置”使用共享 action-button，与发送按钮保持一致的字号、字重、最小高度和圆角，颜色按次要操作呈现。移除先前的独立 10px 文本按钮规则，以及已无 DOM 引用的旧 ai-settings 表单样式。

## 统一 AI 服务发现反馈

设置页、阅读面板和划词卡片共用加载状态、纯文本错误和“重新读取”按钮。错误有最大高度与键盘焦点，阅读面板的反馈区可随可用高度收缩，划词卡片沿用自身滚动区。按钮与字体使用共享规则。

阅读面板在服务未载入或读取失败时保留问题草稿、禁用发送；重读成功后不自动发送草稿。切换已载入服务不重新查询。划词卡片明确区分读取失败与成功发现但未配置服务：前者重读，后者提供设置入口；重读恢复后只执行用户先前请求的一次操作，关闭卡片则放弃后续启动。

## 收集分类的可见性与可逆编辑

已保存的分类即使暂时没有本地文章、未出现在最新可用列表中，也继续显示复选框。提示明确说明这些已选分类仍参与筛选，用户可以取消；本次编辑操作过的选项保留到编辑结束，取消后仍可重新勾选，不因一次分类发现而丢失。目录提供的标签和计数优先；仅从保存范围恢复的选项不虚构计数，完整长名称保留在悬停提示中。

“读取可用分类”依据分类发现能力显示，历史选项依据历史导入能力显示。读取按钮复用共享 action-button 的字体、尺寸、圆角和状态，删除独立的小字号规则；读取失败保持已有选择，继续允许重试。

## 收集范围读取反馈

收集范围尚未载入时，在原位置显示加载状态；读取失败时显示可聚焦、有限高度的纯文本警报和共享样式的“重新读取范围”按钮。名称和文件夹草稿保持可编辑，提示明确说明这些配置仍可保存。

读取错误与保存、刷新等操作错误分开显示，不能互相覆盖或清除。重试只读取范围，恢复后显示真实已保存的选择，不自动保存或清空范围；关闭或替换配置窗口后，迟到结果不再生效。
