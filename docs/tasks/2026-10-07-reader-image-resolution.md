# 任务：内置阅读图片清晰度

状态：完成（保留在线资源限制）

## 目标与范围

- 内置阅读优先使用作者明确提供的高分辨率正文图片，保留原有图片安全边界、图注、原文链接及同块去重规则。
- 修复共用图片选择与同图去重；不修改文章抓取、图片代理协议、数据库或已保存的阅读状态。

## 根因与契约

- 19:06 开始调查，工作区干净。`reader-media.ts` 原先把 `data-actualsrc` 排在响应式候选前、只保留 `<picture>` 第一组 `<source>`，同一媒体块去重时无条件保留先出现的图片。四种确定性夹具在修改前均复现低清图被选中的问题。
- 图片来源按作者的声明证据选择：只把图片专属链接视为原图入口，比较所有 `srcset` 分辨率候选；同一媒体块里，仅在按现有规则可证明是同一图片的生成尺寸时比较尺寸并去重，不跨正文位置、图注或不同查询参数猜测。
- 高分辨率 URL 仍须经过公共 URL 校验；图片加载仍由现有浏览器与受 robots 限制的本地代理负责。无法从网页结构证明存在更清晰版本时，不凭空改写 URL。
