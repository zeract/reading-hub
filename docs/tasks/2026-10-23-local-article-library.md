# 已取得正文与图片的持久化

状态：实现与验证完成（2026-10-23 22:33 开始；10 月 24 日恢复并完成最终验证）

## 目标与契约

按用户授权替换“原文临时读取、只保存卡片”的旧契约。所有来源使用统一的 ArticleDocument 与本地图片存储，不增加操作按钮；Feed 仅提供节选时不冒充原页全文。原页/Feed 删除、断网和进程重启不影响已成功保存的内容。图片未取得时明确保留失败/待处理状态，不声称全文离线完整。

## 根因与实施范围

- `parseFeed` 丢弃正文；`ArticleReader` 每次依赖网络；图片代理仅内存 LRU。
- 新增随文章级联删除的正文与媒体表；正文由现有净化/结构转换生成，持久化结构树而非远端 HTML。
- 同步的正文和卡片、检查点、HTTP 验证器同事务；异步图片任务持久化，退出取消、重启恢复。网页首次读取和新收集条目的有界补正文共享同一路径；只有 Feed 内容时继续尝试原页，成功升级，失败保留。
- 原文、中文改写图片共用本地优先 IPC，保留公共地址、robots、类型/大小及取消边界；不保存 Cookie、凭据、原站脚本或视频。
- 保留已有好稿，摘要、空响应及失败不能覆盖正文；历史未知关系不猜测，不自动遍历历史归档。

## 验收

- 确定性跨来源案例：Feed 移除/304、网页拒绝、断网、关闭重开数据库、图片全部离线加载、共享来源删除、写入失败回滚与迟到请求、重试/权限失效。
- 单元/集成、构建、样式、真实 Electron 离线重启、全应用视觉、全来源在线最新/历史审计分别报告；不调用模型。
- 数据库升级在副本和新库验收，不修改旧改写或凭据，不通过现场批量重抓替代流程修复。

### 本轮结论与修复

- 固定清单 618 条（先前 611 条之后后台增加 7 条）；其中 255 条旧 `permanent:unknown` 对应 252 个地址，全部经生产下载器逐项复核。211 条记录现已恢复，44 条实际超过 8 MB；未放宽大小限制。
- 软件缺陷：SVG 导出器的普通外部 DOCTYPE 被一律拒绝；纯文本/通用二进制 MIME 的合法 SVG/JPEG 无法识别；响应头之后发生的超时或断流没有包装为可重试网络错误；持久化诊断将格式、大小和传输失败合并为永久未知，且后台 HTTP 重试集合与前台不一致。
- 修复：剥离无内部子集的 SVG 外部声明，继续拒绝实体/内部子集，净化后不保留 DTD、脚本和远端子资源；对通用 MIME 采用位图签名或同一 SVG 根节点验证与净化，明确 HTML 不重新解释；响应体网络错误使用既有有限重试；类型、大小、SVG、重定向、HTTP、robots 分别保存固定类别，前后台共用瞬态 HTTP 集合。旧未知状态在原三次任务预算内重新分类，新未知状态不进入兼容重试循环。
- 271 条 robots 失败逐项核对：182 条原地址被拒绝，89 条原地址允许但完整生产重定向链被最终地址禁止（47 条为 Notion 图片目标、42 条为 GitHub 路径）。没有改写地址或绕过规则。其余 89 条保留明确 HTTP 失败（404×81、403×3、401×3、400×2），3 条 robots 获取仍暂不可达。
- 历史数据修复：原失败清单和来源规则保留临时备份；通过既有图片存储 API 将 211 条恢复记录落盘，44 条更正为 `size_limit`。修复后固定范围剩余 407 条，均有明确类别，不再有未知原因。211 条记录对应 208 个地址；先逐张禁网解码，写入后在另一个 Electron 进程从真实 SQLite 读取并再次比对字节、解码，208/208 通过，网络请求为 0。
- More than code：最近五次同步只有一次渲染超时，其后自动恢复。现场静态 HTTP 200 用时 6.438 秒，浏览器渲染 15.546 秒；两者同一规则得到完全相同的十个标题/地址，没有 Feed。依据对照结果使用 `replaceAutomaticRule` 校正该来源遗留的自动 `rendererRequired` 标记，不删除文章、不改人工规则、不加域名判断。生产同步成功，渲染调用为 0；总计 75.633 秒，因为首页仅一条发布时间可用，其余九条沿现有有界流程逐页补日期。此次移除不必要渲染依赖，没有声称消除所有网络等待或推断出历史超时的具体请求。
