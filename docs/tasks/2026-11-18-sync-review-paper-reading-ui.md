# 任务：同步与存储审查规范、纸感阅读布局

状态：完成

## 目标与范围

- 将状态归属、事务成功点和失败与迟到响应写入工程规则及现有任务模板。使用真实存储 worker 的回滚测试作为验收示例。
- 参考 [PaperRss 三栏与阅读截图](https://rss.1leaf.cc/zh-CN/) 的紧凑导航、连续文章目录、浅色纸面和正文留白，为 Reading Hub 的现有功能调整界面。保留本项目的标识、字体、强调色、版本切换、键盘顺序及无障碍状态。
- 仅调整界面布局与样式以及协作规范。新增产品功能、历史数据改写、在线采集和实际模型调用不在范围内。

## 根因与契约

- 现有规范要求检查竞态和事务，但任务模板未单列状态归属、成功点、迟到结果的证据。现有 `storage-worker.test.ts` 已有可以复用的事务失败及删除后拒写案例。
- 原有三栏已使用暖纸色。实际实现使用两条较高的顶部带、宽导航列与顶部文章元数据。将标题栏压到原生控件区域，文章列表以标题为首、来源与日期收在元数据行，保留搜索和操作。
- 当前视觉契约见 [界面规范](../ui-design.md)。
