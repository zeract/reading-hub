# 任务：中文改写链接文字去重与术语保留

状态：完成

## 目标与范围

- 新生成的中文改写中，链接锚文本只显示一次；原文有意重复的文字不能被误删。
- 专业术语在中文译名不通行或容易失准时可直接保留英文，不强制逐词翻译。
- 不重新生成或静默改写既有已保存稿件，不更改原文、链接目标和阅读器通用渲染。

## 根因与契约

- 已验证：段落协议把链接作为带 ID 的引用交给模型，但 `prepareRewriteParagraphs.restore` 仅验证引用数量、嵌套和非空，不检查紧邻链接的重复锚文本；渲染端按文档树逐节点显示，故如实呈现模型输出的两份文字。
- 已验证：当前提示词虽允许必要时保留英文术语，但优先要求“准确、通行的中文表达”，容易把英文专业词强行译成不通行中文。新提示词应明确以领域通行性和准确性优先。
- 仅在同一段落、紧邻链接、可见文字完全相同且原文同位置未重复时，消除链接外的那份冗余文字。保留引用节点及链接目标。
- 新提示词采用独立版本；已完成的旧版本检查点继续按原版本完成，不额外重复调用已成功分节。
