# 科学空间原页读取与 Feed 回退

状态：完成回退恢复修复；保留远端读取与历史公式限制

## 目标与证据

- 原页可用时直接显示原页；站点暂时拒绝读取时保留 Feed 内容，并允许用户重新尝试现有读取流程。
- 2026-10-20 21:35（北京时间）开始调查。工作区干净，真实 robots 仅禁止 `/search/`。最新样本 `/archives/11980` 首次 HTTP 403，随后同一路径 HTTP 200；隔离 Chromium HTTP 403。历史 `/archives/11854` HTTP 200。实际 ArticleReader 在原页响应 200 时返回普通 article，而非 feed_body。没有固定 Feed 优先策略。
- 根因是站点间歇拒绝原页，加上 Feed 回退成功后没有就地重新读取入口；现有提示错误声称“原页未被自动读取”，还把 Feed 正文一概暗示为不完整。

## 修改与验收

- 合并 Feed 正文/摘要提示，按实际模式标明内容来源，不声称禁止读取或未尝试读取。
- 复用现有读取与取消流程提供手动重新读取；没有后台重试循环。重新读取关闭旧 AI 与划词上下文，迟到结果仍按请求身份处理。
- 不改变网络、robots、访问控制、正文净化、公式或数据库；不迁移历史数据。
- 生命周期/提取局部测试 125 项通过，新增科学空间“403 → Feed → 用户重读 → 原页恢复”回归通过。`verify --visual` 的全量测试、构建、样式均通过；受限图形环境启动 Electron 时 SIGABRT，获准的桌面环境中复用相同构建运行视觉夹具通过。真实站点的 HTTP 403 仍属外部限制，不能承诺通过本地补丁消除。
- 在线最新样本 `/archives/11980` 原页恢复后 48 个公式全部渲染；额外旧文 `/archives/11854` 的 153 个公式触发既有 TeX 降级，未记为通过。当前修改没有触及正文/公式管线，该问题需另行定位，不能以最新样本代替旧文验收。
