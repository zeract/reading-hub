# 博客阅读正文边界与美元价格

状态：完成代码、数据修复及自动验收；2026-10-24 21:14 开始。

目标：修复 Simon Willison's Weblog 的内置阅读排版，以明确正文身份为边界，不复制原站样式、不加入域名或单篇文章补丁。核对最新/历史原页、本地结构与真实阅读界面，修复当前信源已保存的错误正文时先备份并逐条核对，不改变收藏/阅读状态或其他来源数据。

证据：当前实际打开 Introducing Kimi K3.1 Pro。阅读器混入站点标题/赞助栏/Recent articles/侧栏与年份归档；同一价格句中的两个 `$` 被当作一对 TeX。来源列表摘要直接显示 `<p>` 等标签。原页正文有声明所属文章 URL 的 `data-permalink-context` 容器，但现有候选选择没有利用它。历史 Python 文章也具有同一关系。价格问题来自共享美元分隔符未校验开闭边界；摘要问题待核实 Atom HTML 编码。

范围：正文身份选择、美元分隔符边界与 Feed 摘要转换；不修改视觉设计或调用模型。验收分本地确定性回归、真实来源最新/历史提取、历史数据处理、实际 DOM/界面与共享管线来源审计；外部访问限制单独记录。

## 实现与数据处理

正文候选新增唯一匹配当前 URL 的声明及唯一文章页/微格式边界，阻止 Readability 密度评分重新扩展到站点布局。第二轮真实检查发现工具、发布日志、引用短帖使用独立文章页而无 URL 声明，已纳入通用候选；页脚支持两种命名风格。域名、标题和文章 URL 不出现在产品分支中。负例覆盖外站、其他文章、歧义声明；保留代码、图片、署名和链接。

Atom `summary type=html` 实际没有 contentSnippet，原逻辑直接把 summary 当纯文本。现在用 DOM 转换 HTML 摘要，实体只解码一次，去掉脚本样式文本，RSS 元数据版本 8 触发现有卡片正常更新。美元闭合规则防止把两个价格配成公式；在线抽检补充了作者在 TeX 末尾放空格的真实边界，仍保留该公式，并避免其后正常公式与价格串接。

原始 30 篇记录备份在本机临时目录 `/tmp/simon-reader-check/before.json`，不提交用户正文。通过正常 SyncManager/ArticleLibrary、robots 和限速路径更新现有来源：无新增文章，30 篇均完成正文核对和保存，HTML 摘要泄漏归零。文章身份、原链接、发布时间、首次收集/观察时间、收藏、阅读状态及已有改写记录的散列保持不变。未修改其他来源正文或调用模型。一次性维护脚本交付前删除，原始备份保留。
