# 任务：保留知乎被评论标注的作者正文

状态：完成

## 目标与范围

- 用户可观察的预期行为：内置阅读器保留知乎回答或专栏中被行评论/批注包装的作者原文，同时不把实际评论区、评论计数或操作控件混入正文。
- 不包含：不读取 Chrome Cookie、不改变知乎授权会话范围、不保存远端全文，也不改变非知乎站点的评论过滤规则。
- 已确认的决策、授权及限制：仅修复主进程的受限 HTML 提取与净化路径；使用确定性夹具覆盖真实 DOM 的结构性变化。

## 根因与契约

- 已验证证据（文件/测试/样本，不存私密正文）：当前净化流程按 `CommentItem` 类名识别讨论记录，但知乎会在作者行评论包装中复用该类名；现已用确定性夹具复现并覆盖无额外标记的块级包装、标记位于后代、`highlighted` 包装及短回答路径。
- 待验证假设：无。
- 受影响的数据归属、接口、失败/恢复规则：仅打开文章时临时生成净化 HTML；提取失败仍使用既有受限原文入口，不写入正文数据库。
