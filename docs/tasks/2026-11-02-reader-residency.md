状态：完成。

目标：大列表 DOM 随视口有界；原文/改写只保留当前展示正文的树，HTML 仅由统一展示组件生成；版本切换继续从本地文档读取，保留语言选择、图片、AI、键盘和滚动行为。无数据库迁移、模型调用或新界面选项。

证据：2026-11-02 实例连续运行约 70 小时，主进程 footprint 216.8–217.5 MiB、50–52 线程；阅读窗口 571.3→573.9→557.7 MiB，峰值595 MiB；GPU103.7 MiB、网络20.5 MiB。空闲采样未证明持续泄漏。源码确认列表分页追加且所有行同时挂载；阅读 IPC 携带结构树与完整 HTML；原文和改写同时驻留，展示还会再序列化 HTML。高占用的完整归属仍需受控对比，不把这些路径当作全部 558 MiB 的解释。

实现边界：使用 TanStack Virtual 的动态测量和稳定条目 ID，限制大列表挂载，保留逻辑顺序、焦点邻居及首尾键盘入口；选择/搜索变更重置列表，普通刷新和追加不重置。正文 IPC 保留已净化结构树，旧 HTML 兼容保留；AI 按请求从结构/实际正文收集有界上下文。未显示的改写仅读元数据；返回原文/语言版本复用本地存储，迟到响应不得恢复隐藏正文或旧文章。

验收：针对性滚动/大小变化/收藏删除/查询切换/焦点/异步版本竞态回归；原生大列表 DOM与JS堆对比、正文副本/反复切换释放、真实用户库只读样本；构建、样式、原生视觉和离线验收。纯展示投影不改变提取、净化、媒体及生成协议；在线来源审计按最终实际影响确认，不重复此前无关外部失败。旧数据不改动；阶段时间、结果及限制收尾记录。
