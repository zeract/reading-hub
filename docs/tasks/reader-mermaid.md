## 目标与范围

- 原文和中文改写应显示用户示例中的无语言标签流程图，也识别明确标为 Mermaid 的受支持图类。
- 普通代码、无法渲染的图表保留为源码。现有正文可直接重新打开，无需重抓、重译或迁移。

## 根因与契约

- Markdown 围栏与网页原有代码块最终都作为代码资产进入同一个 `ArticleBody`，原显示路径直接输出 `pre`。网页净化也会移除代码语言类，导致明确标记丢失。
- 仅在 `pre` 检查明确语言或无语言标签的 `flowchart`/`graph` 方向声明。已有普通代码语言标记优先。新净化只保留 `pre`/`code` 上的规范化语言类，远端样式和其他属性仍剥离。
- 文档树持有原始代码。正文显示阶段才启动本地工作线程，布局有输入和时间限制。SVG 走静态图片路径。切换正文使旧结果失效，并释放工作线程和 Blob URL。
- [长期文档契约](../structured-article-document.md#持久化与兼容)
