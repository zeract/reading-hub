# 同步复用已保存的发布日期

状态：完成（2026-10-24 11:34–11:38）。

## 目标与根因

通用网页连接器在首页缺日期时，逐篇读取详情页；该步骤发生在持久化去重之前，没有查询已存日期，导致每次同步重复请求。范围为同步上下文、按规范化地址的数据库索引读取和通用补日期流程；不新增界面、负缓存或站点专用判断。

## 契约与验收

- 同步宿主通过只读回调查询本次文章的已存日期，使用与保存相同的连接器规范化路径；连接器不直接访问数据库。
- 首页明确日期优先，其次复用已存日期，再使用 URL 日期或既有受限详情页补取。未知日期仍保持未知，允许后续补取；不伪造日期。
- 复用无需扫描/分页整个资料库，使用唯一规范化地址索引；共享文章可复用，重启继续有效。没有可复用值的预览沿原流程工作。
- 集成回归验证首次采集、重启重复同步、追踪参数归一化、新文章、未知日期、共享来源和首页更新日期。真实 More than code 连续同步计数详情页请求与耗时；数据库副本隔离测试，不改变原文或阅读状态。
- 改动未涉及正文提取与媒体展示，不重复全来源正文审计或视觉验收；运行相关测试和统一 core 门禁。

- 11:34–11:36：确认连接器与持久化之间缺少元数据复用通道；加入宿主只读查询，并完成跨重启/共享来源等集成回归。读取当前本机资料库确认 More than code 的十篇文章均已有日期。
- `npm run verify` 通过：210 个测试文件、2169 项测试、构建、工作流与样式门禁通过；核心报告 `.verification/publication-date-core.json`。异常和取消仍沿原同步生命周期；未知日期、详情页错误不伪造日期，源码不新增凭据、IPC 或重试。
