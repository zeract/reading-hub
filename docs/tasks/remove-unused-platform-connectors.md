# 任务：移除 X 动态与小红书专用连接器

状态：已完成实现与本次范围验收

## 目标与范围

- 添加来源只保留网页 / Feed、知乎动态与学术作者；删除 X 与小红书专用表单、回调、IPC、连接器、OAuth 和平台配置代码。
- 普通 RSS/RSSHub Feed 的订阅、图标识别和动态 Feed 正文阅读继续通过 RSS 管线工作。
- 旧专用来源在升级时转换为停止同步的手动来源，保留标题、分类、文章、归属、已读、收藏和中文改写；旧平台账号凭据经 Keychain 清理后删除账号记录，失败可在下次启动重试。

## 根因与契约

- `source-dialogs.tsx` 的两个专用选项分别调用 `x:connect` 和 `xiaohongshu:subscribe-profile`，运行图同时注册两个连接器；仅隐藏入口无法移除后台能力。
- `SourceKind`、来源服务、预加载、能力判断和平台测试仍有专用分支，须同步删除。
- 升级只变更已删除连接器的来源配置与调度状态；不按 URL 域名处理 RSS 来源，避免误停 RSSHub。
- 不新增网络读取或模型调用；取消订阅仍遵循现有删除规则。
- 开发启动与生产构建按 TypeScript 配置清理无对应源码的旧编译产物，避免删除的连接器仍被打进 DMG。清理限定在 `dist/main`，不跟随符号链接，不处理用户数据。
