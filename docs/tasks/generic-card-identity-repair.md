# 任务：通用网页文章卡片身份修复

状态：完成（等待下次普通刷新回写现有来源卡片）

## 目标与范围

- 用户可观察的预期行为：通用网页列表中同一文章的标题链接和“文章详情 / 阅读更多”等操作链接不得生成冲突卡片；自动规则应识别文章卡片根节点，保留标题、发布日期和摘要。
- 不包含：不按站点域名硬编码；不递归分页；不导入 Recsys Frontier 的完整历史目录；不改变 Feed、robots 或阅读器行为。
- 已确认的决策、授权及限制：本次只在下一次正常刷新中修复当前首页可见的 Recsys Frontier 条目，保留既有阅读/收藏状态，不自动导入其 373 篇历史文章。

## 根因与契约

- 已验证证据（文件/测试/样本，不存私密正文）：该来源的自动规则为 `a[href*="/article/"]`。每张 Recsys Frontier 卡片有同一 URL 的标题和“文章详情”链接；24 个原始候选折叠为 12 个 URL，后者覆盖标题。个别文章还会在侧栏出现同 URL 的标题链接，故“所有同 URL 链接必须在同一容器”的初版安全条件过严。首页存在分页和内嵌历史目录，但其不属于本次收集范围。
- 已验证实现：按规范化 URL 合并候选并按文章元数据质量选择记录；自动规则只在标题链接与 CTA 的一对链接能推导出受边界限制的共同卡片容器、该选择器精确匹配当前卡片且修复前后 URL 集合完全一致时替换。手工规则及合法的整卡链接保留原有所有权。
- 受影响的数据归属、接口、失败/恢复规则：仅 `generic` 连接器的自动规则及该来源已有 URL 的元数据更新；canonical URL 不变，数据库已有的阅读/收藏状态保持。
- 持久化或协议变更的兼容与回退方式：提升自动规则修订号以触发一次正常刷新；手工规则不自动替换。

## 当前进度与交付

- 已完成：根因定位；通用候选质量合并；受边界限制的标题/CTA 共同卡片识别；旧自动规则一次性修订触发；确定性提取、同步与保留状态回归。
- 实际公开页面核对：只读加载 Recsys Frontier 首页；修复后旧规则可迁移到精确的重复卡片选择器，得到 12 条当前首页文章，首批样本均具真实发布日期和摘要。页面卡片未提供可提取图片时保持为空；未写入本机数据库，也未遍历分页或内嵌历史目录。
