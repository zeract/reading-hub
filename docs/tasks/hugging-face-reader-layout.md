# 任务：Hugging Face 博客嵌入内容排版

状态：完成

## 目标与范围

- 用户可观察的预期行为：Hugging Face 博客正文中的交互图表不再被静默删除；内置阅读器显示紧凑说明和可访问的原文入口，其余正文排版保持正常。
- 不包含：执行原站脚本、加载第三方 iframe、保存全文、改变其他来源的同步行为。
- 已确认的决策、授权及限制：用户允许添加 `https://huggingface.co/blog/feed.xml` 用于检查；已用应用自己的 robots 感知网络客户端读取 Feed（HTTP 200，前三条有效）和三篇公开文章，但没有持久化订阅。

## 根因与契约

- 已验证证据：三篇真实页面均以 `.blog-content` 包裹返回链接、标题、元信息、投票及作者卡片，最后一个直属 `div` 才是作者正文。旧提取结果在最新一篇的正文前出现 `Back to Articles`、作者名单，文末出现 `Models mentioned in this article` 等页面模块；正文图像计数从 35 降到 3 后仍保留文章图像。Hugging Face 官方 `tokenizers-v1.md` 及实际 HTML 均含五个可视化 iframe，每个原本已有 `figure` 包裹；旧噪音规则直接删除 iframe，初版替代又形成嵌套 figure。最终在线回放为五个 iframe 对应五个单层 figure。
- 待验证假设：其他 Hugging Face 页面模板是否有不同的正文容器；后续模板变化须以在线样本复核。
- 契约：仅对 `huggingface.co/blog/` 使用经真实 DOM 验证的内部正文边界；其他来源仍走原提取选择。只转换具有可见尺寸、有效公共 HTTPS 地址的嵌入框；不加载其资源，不保留原站样式或脚本；不可见/追踪框仍删除；生成的链接只指向已校验的文章原页。
