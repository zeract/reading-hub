# 任务：知乎授权文章 HTTP 403 的安全阅读降级

状态：完成

## 目标与范围

- 用户可观察的预期行为：已从知乎关注页收集、但知乎正文页当前返回 HTTP 403 的文章，内置阅读器显示该条已收集的摘要，而不是空白失败页；原文入口仍保留。
- 不包含：不绕过知乎的 403、登录、验证码、robots 或访问控制；不读取 Chrome Cookie、不调用私有 Web API、不保存原文全文。
- 已确认的决策、授权及限制：只使用该条目 SQLite 中已保存的标题、作者、时间和摘要；摘要过短或非知乎关注来源时仍保留原错误。

## 根因与契约

- 已验证证据（文件/测试/样本，不存私密正文）：本机条目属于 `zhihu_follow`，因此 `ArticleReader` 已使用 `ZhihuFollowConnector` 的独立会话；该来源最近同步成功。该 URL 的 403 页面为知乎安全验证响应，不是文章 HTML 或普通登录失效。`observeRenderedPage` 在主框架响应为 403 时在 DOM 提取前抛出 `RenderedPageHttpError`，故正文提取、公式处理和评论净化均未执行。
- 待验证假设：无。不会把安全验证视为可由自动重试、伪造请求上下文或改写 User-Agent 解决的问题。
- 受影响的数据归属、接口、失败/恢复规则：仅在 `zhihu_follow` 且会话读取明确收到 `RenderedPageHttpError(403)` 时，从已持久化的卡片摘要构造临时、已净化的 `source_summary` 阅读文档；无有效摘要时保留 403。阅读器不写回任何正文或会话数据。
