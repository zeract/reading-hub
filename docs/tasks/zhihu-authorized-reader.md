# 任务：修复授权知乎回答的内置阅读

状态：完成（线上授权审计受当前 Electron 启动异常限制）

## 目标与范围

- 用户可观察的预期行为：授权“知乎关注动态”中的目标回答能在内置阅读器显示，包括短回答和异步水合的回答正文。
- 不包含：不读取 Chrome Cookie、不访问知乎私有 Web API、不以卡片摘要冒充原文、不放宽普通网页的正文防噪规则。
- 已确认的决策、授权及限制：仅使用应用既有的独立知乎授权会话；目标条目为本机已收集的回答 URL，正文不持久化。

## 根因与契约

- 已验证证据（文件/测试/样本，不存私密正文）：`d107acaf-bb41-47eb-b243-3542c965991b` 是 `zhihu_follow` 回答；读取链路在授权页面成功返回、提取为空时才抛 `ArticleContentUnavailableError`。通用候选根的 40 字门槛会丢弃已身份绑定的短回答；授权窗口目前仅固定等待 900ms，未等待目标回答正文水合。
- 待验证假设：知乎的 `data-zop` 可包含超出 JavaScript 安全整数范围的回答 ID，身份解析须保留原始数字字符串。
- 受影响的数据归属、接口、失败/恢复规则：只在内存中读取已授权页面；按请求 URL 的回答 ID 绑定正文，未确认身份或未形成正文仍明确失败，不能显示其他回答。
