# 聚合器架构检查与重构记录

检查日期：2026-09-06。

保留 Electron 主进程、受限 IPC、内置连接器、SQLite 和 React 的现有分层。本轮修改解决订阅生命周期、阅读状态、时间语义和异步任务边界的问题，不引入新的服务或框架。上一轮同步事务重构保留在提交 `10102cb`。

## 当前设计与修改

| 根因 | 修改后的契约 |
| --- | --- |
| 删除来源同时删除独有文章，订阅与本地阅读资产绑定。 | `subscriptions.subscribed` 表示是否订阅；取消订阅立即取消同步、停止轮询，保留内容、收藏和来源关系。已取消来源可在侧栏重新订阅。旧删除 IPC 兼容为取消订阅。 |
| 卡片删除不可撤销，校准或维护可能再次清除用户保留的内容。 | 删除写入墓碑并隐藏卡片，支持即时撤销和“最近删除”恢复，重启后仍有效。清理来源仅隐藏独有且未收藏的卡片；校准和共享维护原语保留收藏、墓碑记录及跨来源关系。 |
| 点击卡片就标为已读，加载失败也从未读列表消失。 | 只有当前文章成功进入 React DOM 后才自动标为已读。失败、过期响应和仅打开受限原文窗口不计为已读；随后手动标为未读不会被立即覆盖。 |
| 发布时间与发现时间混用，历史回填干扰新内容列表。 | 默认“新收集”按首次入库时间与 ID 稳定分页；公开归档补回的历史条目标记为 `history`，单独查看。重复同步不重写首次收集时间或类别。“今日发布”只使用真实发布时间，未知日期不会冒充今日发布。 |
| 搜索强制选择单个来源，无法找回其他订阅或已取消来源中的内容。 | 全局与来源视图共用数据库元数据搜索；支持标题、作者、摘要，保留 LIKE 字面量转义和每页数量限制，不增加全文索引或正文持久化。 |
| 来源出错难以发现，类型和账号入口占据普通添加流程。 | 侧栏显示异常状态，来源列表提供设置入口；设置显示错误、最近成功时间、下次检查时间以及相应操作。公共链接为默认添加入口，账号/作者与类型调整逐层展开，共享能力模型约束刷新及恢复入口。 |
| 订阅和来源分别维护连接器、账号及配置，存在双重权威。 | 订阅是连接器元数据的写入权威；SQLite 触发器维护旧来源列的兼容投影，现有只读脚本仍可使用来源结构。来源类型切换同时清除旧账号、配置和协议游标。 |
| 每 15 秒重读已加载页面，空闲成本随历史翻页增长。 | 事务提交后发送版本通知，渲染器合并通知并刷新有效页面；每 60 秒只检查轻量版本和跨午夜边界。保留导航、翻页、异步旧响应的保护及错误重试。 |
| 退出只等待连接器，慢网络和分页延迟关闭。 | 同步上下文携带取消信号，贯穿 HTTP、响应正文、分页、重试等待和后台窗口。取消不记为失败、不推进游标；退出停止接入、取消任务、等待清理，最后关闭数据库。 |
| 学术来源未配置的提供方被计为成功；X 返回的异步请求未进入账号失效处理。 | 只统计实际配置的学术提供方；全部失败正确报错。X 等待异步结果，401 标记账号失效，403 与取消不冒充令牌失效，临时刷新网络失败不强制清除账号状态。 |
| 阅读审计打开正式数据库也会执行新版迁移。 | 审计先通过 SQLite 只读连接和 backup API 创建包含 WAL 的一致快照，仅迁移临时副本并在结束时清理。 |
| 全来源审计发现已渲染 KaTeX 的注释源码在净化后泄漏。 | KaTeX 与 MathJax 共用显式 TeX 注释恢复路径，重新安全渲染；不信任原站样式、不猜测普通文本、不转换代码块。 |

## 迁移与安全边界

数据库版本从 5 升级为 6，新增订阅状态、首次收集类别、最近成功时间和库版本状态。已有内容保守标为 `current`，不会根据文章年龄猜测历史回填，也不会移动或删除既有收藏。后续明确的归档回填才使用 `history`。

公开 HTTPS 校验、显式本机 Feed 例外、robots、限速、正文净化、Keychain 与独立知乎会话边界保持不变。取消知乎关注订阅会清除该授权会话；再次使用时可重新登录。没有读取真实令牌进行测试，也没有增加正文、AI 问答或凭证的持久化。

## 验证

- `npm test`：58 个文件、405 项测试通过。覆盖新增、去重、发布时间及收集时间分页、失败退避、账号失效/取消、事务回滚、来源变更、重启恢复、WAL 快照、已读竞态和通知合并。
- KaTeX 回归测试在修复前实际失败：2 个作者公式均未进入公式模型；修复后两个公式完整渲染，代码示例保持原样。
- `npm run build`：主进程、渲染器 TypeScript 和 Vite 构建通过。
- `git diff --check`、`npm run audit:style`：通过。
- `npm run audit:visual`：确定性夹具检查 1024、1280、1440（125%）、1720 四种视口，以及公式、编号、图片、表格、代码、滚动、AI 面板、侧栏、全屏与沉浸状态。
- `npm run audit:renderer`：使用真实 React、沙箱 preload 和内存 SQLite，验证新收集、全局搜索、历史回填、失败/成功阅读、取消订阅、删除/恢复，以及三种实际窗口布局；截图仅输出到系统临时目录。
- `npm run audit:reader`：隔离快照中的 32 个来源、63 个最新/历史样本；额外启用块公式的真实 DOM 检查。结果为 57 通过、4 远端首图连接问题、1 首图超时、1 受限原文路径跳过。科学空间、普通网页/RSS、知乎关注内容均有实际样本，AI 公式由离线与视觉夹具覆盖。
- 修复后的 turbopuffer 样本：15 个公式全部渲染，其中 2 个块公式，无回退、丢失或源码泄漏。

## 已知限制

- 4 个图片连接失败与 1 个图片超时来自远端资源，未绕过网络或访问限制，不能宣称全部线上样本通过。受限原文样本不执行自动提取。
- 升级前已物理删除的卡片无法凭空恢复；新删除记录保留在本机，当前没有自动清空回收记录的策略。
- 旧文章缺少历史入库类别，无法可靠追溯其是否来自过去的回填；迁移因此保持保守默认值。
- 全局搜索仍扫描本机卡片元数据，未引入全文搜索引擎；多次 IPC 分页不是同一数据库快照，通知与版本检查负责后续校正。实际变更刷新成本仍与已加载页数有关。
- X/学术授权错误通过确定性模拟验证，未使用真实授权账号发起写操作。原有 renderer chunk 超过 500 kB 的构建提示仍存在。
- 没有新增长期协作要求，因此本轮不修改 `AGENTS.md`。主进程、preload 和渲染器均有修改，使用新代码需要重启开发应用；首次启动会自动迁移数据库。
