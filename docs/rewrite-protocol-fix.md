# 中文改写输出协议修正

日期：2026-09-12。范围仅限通用改写协议、诊断及兼容检查点，不调整博客提取规则或阅读器展示。

## 问题与修改

SDLC 文章的旧任务共 16 节，已保存 2 节，第 3 节触发段落标记校验。失败响应未保存，不能断言此前具体缺少哪个标记。代码中存在“不输出内部 ID”和“必须保留 B 标记”的矛盾指令，且将多种协议失败合并成同一句提示。

新协议消除上述冲突，使用简短的正文块边界，源文本存在标记碰撞时才增加命名空间。资产仍使用源内容绑定的保护标记。只剥离完整包住首尾预期块的 Markdown 围栏，随后继续逐块校验；缺块、重复、乱序、额外正文、空块、结构变化和资产损坏分别报告程序生成的诊断类别。错误包含失败节号，不保存失败模型正文，不增加自动审阅或重试调用。

协议版本从 7 升至 8。此次仅改变输出封装，内容转换、分节和原有成功输出的语义未变化，因此显式兼容同一原文指纹、标题、地址和模型设置下的 v7 成功检查点。之后保存为 v8，不重新生成已完成分节。其他版本不自动兼容。

- 测试只发送该节，未重新生成整篇，未把测试结果或新检查点写入用户数据库。临时结果留在本机临时目录，不提交原文或生成稿。
- 本次未修改共享原文提取、净化或前端样式，故不重复全来源在线抽检和视觉审计。实际模型验收覆盖失败节，不代表已经完整生成其余 13 节，也不能保证以后模型绝不违反协议。
