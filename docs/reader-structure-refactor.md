# 正文结构与图片生命周期重构

日期：2026-09-12。

## 实现范围

- 新稿在每个源块完成结构与资产恢复后，保存块标识、分节、目标偏移、源/目标 SHA-256、类型及资产归属；检查点携带同一份关系，恢复不增加模型调用。存储格式版本与提示词版本独立。
- 旧稿首次读取时无损迁移为派生结构索引，不推断已经丢失的原文对应关系。迁移事务先保留一份旧结果，备份随改写/独有文章删除；原文正文不入库。未来格式不会降级覆盖。旧稿 Markdown 保持原样，迁移不调用模型。
- 队列隔离无法解析的任务设置；显式重新排队可替换损坏设置而保留旧结果。结构校验覆盖指纹、边界、顺序和正文覆盖，失效索引退回派生索引。
- 原文图片的代理回退与改写图片共用前端调度：接近可视区域才进入 IPC，每个渲染窗口最多四个并发。切换/关闭时移除排队项并取消活跃请求，迟到响应不能写回旧文档。原文已有的浏览器原生加载仍保留。
- 主进程同址合并、缓存、robots、公共地址、媒体类型与大小边界保持不变。网络失败及暂时性 HTTP 状态最多自动重试一次，退避可取消；永久错误不重试。IPC 仅传递固定错误代码，不传 URL、远端响应或凭据。图片失败沿用现有安全原文入口，不增加操作控件。
- `article-reader.ts` 保留网络获取、身份校验、语言状态及降级编排；`reader-extraction.ts` 处理内容选择、语义标准化和安全输出；`reader-media.ts` 管理媒体候选与归属；`reader-math-macros.ts` 负责不执行脚本的宏解析。保留现有提取入口，避免调用方迁移产生行为差异。
