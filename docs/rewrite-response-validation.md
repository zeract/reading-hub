## 当前契约（2026-10-23）

模型响应必须是完整 JSON，或单个完整 JSON/无标签 Markdown 外围围栏。解释文字、多个对象、截断和猜补仍被拒绝。引用的数量、开闭形式、源父级及资产目标均由程序校验，不根据译文猜测链接归属。

每节先解析全部收到的文字节点，再收集每个坏段落的第一条引用诊断，与缺失节点合并。仅将受影响的完整段落交给同一个局部修复请求，成功段落保持不变。修复响应必须重新通过完整校验，含错误的中间文档不能返回或保存。不得先修第一个坏段落，再因其他坏段落耗尽预算而失败。

`repair.issues` 只包含程序生成的段落 ID、已知引用 ID（或 unknown）与固定错误类别，不包含模型正文。模型从受影响段落的原始输入重新改写，不接收坏响应。提示明确引用移动单位是完整子树：并列引用分别闭合，子引用不能脱离原父级，闭合标记与当前栈顶一致。

JSON 格式错误的整节重试、漏节点与引用局部修复共享每节一次预算。传输失败不自动生成重试；取消后不保存迟到响应；修复仍失败则停止，保留已成功分节与旧稿。

本次未改变输入源树、段落切分、指纹、输出 schema 或资产校验语义；引用说明只是明确既有规则，恢复调度纠正为一次处理全部已发现问题。因此保留原提示版本与匹配的 v12/v13 检查点，不导致已验证分节重新生成。不修改用户数据库。
