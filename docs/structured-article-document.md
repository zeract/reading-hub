# 统一结构化阅读文档

## 已实现的边界

原文经现有 robots、身份核对和 HTML 净化路径后，转换为 `ArticleDocument` v1。树包含文字、HTML 语义结构、不可编辑资产（公式、代码、图片、视频）以及推荐卡片。标签和属性按允许列表验证；树没有 raw HTML 或脚本节点。公式保留语义 TeX、编号以及程序生成的安全展示树，避免把科学公式再次转换成 Markdown 丢失排版。

原文与中文都使用 `ArticleBody`，进入相同的正文样式、图片代理/失败回退、视频加载、链接点击及划词路径。AI 对话仍可用 Markdown 表达回答，但文章不再使用 AI 消息渲染器。重复轮询相同稿件不会重置媒体请求。封面也归属于文档。

第 11 版兼容协议的改写请求只包含文字节点 ID、纯文本及带身份和资产顺序的只读上下文。程序复制源树并应用文字补丁；模型不能修改链接网址、结构、图片、代码、公式等属性。分节以完整段落为边界，最多约 6,000 字符/48 文字节点，完整段落硬上限 9,000 字符。上下文预算独立有界。中文语法可以显式返回空字符串，但不能缺少记录，也不能让整个段落、链接或卡片标题变空。有效响应若漏节点，只对受影响的完整段落进行一次局部修复；失败不会进入循环，也不保存不完整分节。

公式资产拥有独立的展示节点命名空间；临时 SVG ID、几何变化不影响后续文字节点 ID 或源指纹。取消、节点数量/身份、长度、空段和持久化检查继续有效。

## 持久化与兼容

结果 schema v2 新稿只保存中文文档树，不重复存储 Markdown、旧偏移索引或原文副本。读取时按需派生 Markdown 供兼容接口/导出使用。原文树始终临时；只有旧检查点需要的净化导入 HTML 作为临时兼容输入，不能进入持久化结果。

v1 稿件在读取时转换为同样的文档树，仍保留原 Markdown 和一份级联删除的备份，迁移幂等。不存在的推荐卡片关系或已丢失的媒体不能从旧文本猜出。不支持的版本或损坏树保留原始记录并明确报错。

旧 v7–v10 检查点沿用旧转换和分节协议完成，避免重跑成功章节；全新生成使用 v11 文档管线与独立结构指纹。结构化检查点只保存已验证的中文文字补丁，恢复时再次核对 ID 和正文可读性。已有稿件不会被失败任务覆盖。

## 2026-09-12：第 12 版段落协议

新任务将完整段落视为语言单位，保留程序管理的行内引用。模型可以在段内调整词序及链接/强调/行内代码的位置，但不能修改资产、引用数量、嵌套归属或跨段移动。正文仍保存为同一文档树。标题作为首次请求中的独立节点生成，保存 `rewrittenTitle`，在英文原题下显示。纯资产文章不调用模型。

第 12 版最初对部分技术术语举例；2026-09-13 已删除这些固定示例，改为领域理解、准确性、流畅度、原文语气与术语一致性的通用要求。沿用上一节的精简上下文，不新增默认审阅。请求不再重复提供相邻待译节点 ID，避免模型将其也返回；DeepSeek 改写使用 JSON 输出模式，普通问答不变。每节漏段或引用错误合计最多一次局部修复。已有 v11 成功检查点继续旧协议，新任务以 v12 隔离；真实源结构变化不复用旧指纹。

代码识别在正文选择与净化前消费明确的 `white-space: pre/pre-wrap` 和等宽字体证据，转换成标准 pre/code，远端 CSS 不进入阅读器。不依据 JSON 标点猜代码。

## 2026-09-13：通用翻译要求与 CSS 标签/值网格

提示词参考 [translation-agent 的翻译质量维度](https://github.com/andrewyng/translation-agent/blob/main/src/translation_agent/utils.py)，采用准确性、中文流畅度、作者语气和领域术语一致性要求，不采用其多轮反思流程，也不预设 agent 等词的译法。要求按短语整体含义表达，避免字面拼接和生造术语。输出与资产契约保持不变，仍为段落协议。真实模型两段验证最终一次请求完成；这不能保证任意模型或文章的译文质量。

SDLC 的 Getting started 区域使用 div + CSS grid，标签是 b，值是相邻 div；源 HTML 没有 table。丢弃 CSS 后，原提取管线只留下顺序段落，模型与统一渲染只是继承这种结构缺失。现在在正文选择前读取本页样式中的明确两列 grid 声明，要求同一容器有至少两行一致的标签/值结构、无混杂控件，再转换为 table/th/td。不执行源脚本、不保留源 CSS，不以域名、类名或普通重复 div 判断表格。不能识别所有任意 CSS 视觉布局；不满足证据要求的布局保持原状。

本地 SDLC 完整样本转换出 28 个表格（含原有表格），经整个改写协议模拟往返后 HTML 完全一致。实际 DOM 在 840/1100/1440 窗口及 125% 正文字号下，13 处 Prerequisites 行列对齐，无页面溢出。模拟往返不是整篇真实模型生成，DOM 阻止远端媒体请求。
