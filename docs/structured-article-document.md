# 统一结构化阅读文档

## 已实现的边界

原文经现有 robots、身份核对和 HTML 净化路径后，转换为 `ArticleDocument` v1。树包含文字、HTML 语义结构、不可编辑资产（公式、代码、图片、视频）以及推荐卡片。标签和属性按允许列表验证；树没有 raw HTML 或脚本节点。公式保留语义 TeX、编号以及程序生成的安全展示树，避免把科学公式再次转换成 Markdown 丢失排版。

原文与中文都使用 `ArticleBody`，进入相同的正文样式、图片代理/失败回退、视频加载、链接点击及划词路径。AI 对话仍可用 Markdown 表达回答，但文章不再使用 AI 消息渲染器。重复轮询相同稿件不会重置媒体请求。封面也归属于文档。

新的改写请求只包含文字节点 ID、纯文本及带身份和资产顺序的只读上下文。程序复制源树并应用文字补丁；模型不能修改链接网址、结构、图片、代码、公式等属性。分节以完整段落为边界，最多约 6,000 字符/48 文字节点，完整段落硬上限 9,000 字符。上下文预算独立有界。中文语法可以显式返回空字符串，但不能缺少记录，也不能让整个段落、链接或卡片标题变空。有效响应若漏节点，只对受影响的完整段落进行一次局部修复；失败不会进入循环，也不保存不完整分节。

公式资产拥有独立的展示节点命名空间；临时 SVG ID、几何变化不影响后续文字节点 ID 或源指纹。取消、节点数量/身份、长度、空段和持久化检查继续有效。

## 持久化与兼容

结果 schema v2 新稿只保存中文文档树，不重复存储 Markdown、旧偏移索引或原文副本。读取时按需派生 Markdown 供兼容接口/导出使用。原文树始终临时；只有旧检查点需要的净化导入 HTML 作为临时兼容输入，不能进入持久化结果。

v1 稿件在读取时转换为同样的文档树，仍保留原 Markdown 和一份级联删除的备份，迁移幂等。不存在的推荐卡片关系或已丢失的媒体不能从旧文本猜出。不支持的版本或损坏树保留原始记录并明确报错。

旧 v7–v10 检查点沿用旧转换和分节协议完成，避免重跑成功章节；全新生成使用 v11 文档管线与独立结构指纹。结构化检查点只保存已验证的中文文字补丁，恢复时再次核对 ID 和正文可读性。已有稿件不会被失败任务覆盖。
