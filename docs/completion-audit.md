## 验收结论

逐项核对上述需求、当前实现、回归覆盖和运行结果后，本次架构重构与界面统一迭代完成。当前审查范围内没有尚待处理的可复现缺陷或有证据支持的必要重构点；不继续添加缺少实际需求的抽象或功能。既有本地优先、数据保留、权限和阅读边界均保持。

最后一轮收尾仅补充验收文档，没有产品代码、依赖、迁移或长期协作规则变更。此前实现均已提交并推送；完整重启应用可加载本次持续迭代的全部更新。

## 证据边界

- 线上抽样只能说明此次样本的可读性，不能保证远端站点未来不变，也不能证明所有历史文章均可提取；Feed 正文/摘要回退不等于原站全文读取成功。
- 账号失效与 Keychain 错误路径使用确定性替身；未为验收使用真实账号发起授权写操作。原生 IPC 与网络隔离另有真实 Electron 证据。
- 输入法组合状态用真实 DOM 的合成事件验证；未驱动 macOS 输入法候选窗口或进行完整 VoiceOver 用户测试。
- 历史上已物理删除的数据不能恢复，未知历史收集类别不作猜测；现有搜索基于本机元数据，未新增全文搜索功能。
- 本次验收针对现有功能和约束，不承诺软件永远没有可优化之处；后续新需求、真实性能瓶颈或站点变化应以新证据决定是否继续修改。

## 2026-09-10 图片重复显示修复

确定性用例复现两条路径：懒加载图片被链接/透明容器包裹时，直接兄弟选择器漏掉对应的 noscript 备用图；正文选取高清 srcset 候选后，封面比对丢失了作者声明的低清候选关系。现在统一解析安全的图片候选，在相邻且不含正文/独立图注的容器中合并备用图并保留替代文本和高清候选；封面只在对应图片确实保留于净化后的正文时省略。网页与 Feed 正文共用这一判断。

边界用例覆盖备用图前置/后置、透明链接嵌套、响应式封面、共享占位图的不同照片、不同查询参数的图片，以及作者在不同正文位置复用的插图。去重不增加网络访问，不复制备用 HTML 的事件或脚本，不采用全文图片全局去重。AGENTS.md 已记录上述图片身份和保留规则。

验证：全套 176 文件、1849 项测试通过；合并重复的备用图元数据处理后，85 项正文测试再次通过。构建、样式契约、diff 检查、原生交互及四档视觉审计通过。全来源正文和科学排版检查 31 来源、61 个最新/历史样本，其中 58 通过（53 网页正文、4 Feed 正文、1 Feed 摘要），3 项因远端 HTTP 403 读取失败：知乎关注动态及两篇 Yanyan Jiang 论文。该访问限制不能视作正文通过；可读取的知乎历史样本与科学空间、普通网页/RSS 已覆盖，AI 公式由确定性原生/视觉夹具验证。用户未提供具体重复文章，本次结论对应已复现的两类缺陷及上述抽样范围。重启应用并重新打开文章后使用新的主进程提取逻辑。

## 2026-09-11 招聘误收与采集范围修复

Perplexity Research 的旧规则为整页 `li`，仅带 `rendererRequired` 而没有人工/自动归属。旧兼容逻辑据此把它当成人工规则，跳过自动修复；文章列表和招聘列表又共用重复结构。现在浏览器运行要求不再决定规则归属，保留真正的人工标记及旧字段级选择；自动规则版本提升到 6，以便旧信源重新检查。明确的 publications 分区可保存局部结构路径，刷新时重新识别，跨站链接必须由作者显式给出，不能由异站 base 标签制造。

新增共享内容资格模块，以招聘分区、JobPosting 微数据或明确的 Ashby 职位地址作为排除证据。DOM 提取和校准预览共用分区判断，JSON-LD、Feed 转换和入库前共用地址判断；该限制仅针对网页文章订阅，不改变直接 RSS 或手动保存的范围。没有基于文章标题中的 jobs/careers 单词过滤，也不禁止正常外链。未知招聘系统仍需页面结构证据，这不是对所有网页语义的无误分类器。

维护版本 2 仅清理 generic 来源已知职位地址的关联，复用共享内容重指向、收藏保护及事务机制。真实数据库的只读一致副本验证：指定记录在维护前存在、维护后移除，共清理 3 个招聘来源关联，零失败；第二次执行清理数为 0。真实库由下次应用启动维护，规则在下次成功同步后保存。

验证：`npm test` 177 文件、1854 项通过，`npm run build` 与 `git diff --check` 通过。覆盖实际旧规则的重建页面、跨站研究文章、异站 base 隔离、人工规则、校准预览、重复同步、发布时间、保存入口、收藏及共享内容、维护幂等性；完整测试包含既有失败退避、取消、权限失效和重启路径。未新增 IPC、鉴权或外部请求。未改 UI 或正文渲染，因此未重复视觉和全来源正文审计；原站直接抓取的 HTTP 403 限制仍存在，页面复现基于官网公开分区与本机实际规则，并非宣称完整实时 DOM 已抓取。AGENTS.md 已记录采集范围与规则归属要求。

## 2026-09-11 标题、来源操作与知乎回答身份修复

Perplexity 日期前缀来自整张链接卡片的文本提取，独立日期节点和标题被拼在一起。标题提取现在移除明确的时间节点及独立纯日期标签，保留作者标题本身的日期及嵌套标题文字；自动规则版本提升到 7，既有来源下次同步重新检查，成功遇到的文章更新标题，不伪造或改写发布时间。

来源设置移除仅用于切换连接器类型的高级设置，类型改为只读。按用户要求，完整删除“清理未收藏内容”的 UI、preload、IPC 和数据库方法，保留单条隐藏及撤销功能。取消订阅继续事务删除信源独有文章，包括收藏；其他信源引用的共享文章保留。旧批量隐藏标记不在升级时自动恢复，不擅自更改既有阅读选择。

知乎旧实现把全页多个回答作为候选，并与通用 Readability 竞争，可能选中更长的其他回答或混合正文；关注列表又独立选择链接和卡片元数据。新增共享回答身份模块，以目标回答 ID、页面显式元数据及导航结果校验目标，正文提取只在已确认的回答子树内执行，移除嵌套其他回答；作者优先取目标回答自身的信息。关注采集在同一卡片内绑定链接、作者和摘要，忽略正文引用和嵌套推荐，歧义卡片不入库。无法确认或跳转时给出原文查看提示，不用其他回答替代。没有增加知乎 CLI 或搜索摘要服务，也未绕过现有登录、robots、限流和 HTML 净化边界。

验证：全套 178 文件、1861 项测试通过；随后对作者归属、嵌套卡片、canonical 冲突及嵌套日期边界收尾，最终相关 3 文件、100 项测试通过。最终构建、`audit:style`、diff 检查通过；原生 React 工作流及四档视觉审计通过，涵盖来源设置滚动/保存、取消订阅、窄/默认/宽窗口、125% 字号、图片、表格、代码、公式、AI、侧栏和全屏。检查废弃 API/选择器引用、错误提示、异步保存/刷新及取消路径；没有新增凭据存储或 IPC 权限。

全来源只读快照审计覆盖 30 来源、59 个最新/历史样本：56 通过（48 网页正文、7 Feed 正文、1 Feed 摘要），其中 4 个科学排版样本；2 篇 Yanyan Jiang 论文因 HTTP 403 失败，1 篇知乎历史回答因页面跳转被身份校验拒绝。知乎最新样本是“知乎关注动态”短页面，不能将其审计通过视为目标回答全文验证。用户指出的苏剑林回答未完成线上原文比对，身份混排修复由确定性多回答、嵌套推荐和重定向测试验证；AI 学习公式由原生夹具覆盖。最后的两个防御性边界收紧由相关测试验证，未重复全部线上抽样。临时报告在 `/tmp/reading-hub-finalfix-*`，不提交用户数据库、全文或截图。AGENTS.md 新增长期标题/来源操作与知乎回答身份规则；完整重启应用后生效，重新刷新 Perplexity 来源以更新可再次收集的旧标题。
